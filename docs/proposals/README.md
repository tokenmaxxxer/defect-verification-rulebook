Any phase-1 proposal placed here (or under an issue-scoped proposals
directory) must follow the shape formalized in
`docs/issue-11/proposals/defect-verification-rulebook.md` section (a): a
`files:` header, `Request`, `Constraints`, `What will be done`, `Out of
scope`, and `How it'll be known to work` sections, backed by a scout-brief
with an explicit `Sources:` list and stated sweep mode. See that file for
the full rationale.
